# BattlefieldCommand

## Описание
BattlefieldCommand - это плагин для Minecraft, добавляющий режим командных PvP-сражений с различными классами, автоматической генерацией карт, контрольными точками и интеграцией с голосовым чатом. Плагин позволяет организовать полноценные битвы между двумя командами с элементами стратегии и тактики.

## Возможности
- Автоматическая генерация реалистичных карт для сражений на высоте 200 блоков с ландшафтом (горы, холмы)
- Система классов (штурмовик, снайпер, инженер) с уникальным снаряжением
- Захват и удержание контрольных точек
- Интеграция с голосовым чатом (поддержка простого модуля "VoiceChat")
- Статистика игроков и команд
- Награды за серии убийств
- Радиосообщения для быстрой коммуникации
- Система респауна с волнами
- Наблюдение за игрой в режиме spectator

## Команды
### Основные команды (/bc)
- `/bc setup` - Начать настройку арены
- `/bc join [класс]` - Присоединиться к игре
- `/bc leave` - Покинуть игру
- `/bc start` - Запустить игру
- `/bc stop` - Остановить игру
- `/bc restart` - Перезапустить игру
- `/bc class <класс>` - Сменить класс
- `/bc spectate` - Наблюдать за игрой
- `/bc info` - Информация о текущей игре
- `/bc config reload` - Перезагрузить конфигурацию
- `/bc help` - Список доступных команд

### Голосовой чат (/voice)
- `/voice channel <team|tactical|all>` - Переключить канал голосового чата
- `/voice toggle` - Циклично переключить каналы голосового чата
- `/voice status` - Информация о текущем канале
- `/voice help` - Список команд голосового чата

### Радиосвязь (/radio)
- `/radio <сообщение>` - Отправить радиосообщение своей команде

## Игровой процесс
1. Администратор настраивает арену с помощью команды `/bc setup`
2. Игроки присоединяются к игре, выбирая класс
3. Администратор запускает игру командой `/bc start`
4. Команды соревнуются за контроль над контрольными точками
5. За удержание контрольных точек и убийства противников начисляются очки
6. Побеждает команда, набравшая больше очков к концу матча или достигшая целевого счета

## Классы
### Штурмовик (Assault)
- Специализация: ближний и средний бой
- Оружие: автоматическое оружие
- Особенности: хорошая мобильность, среднее здоровье

### Снайпер (Sniper)
- Специализация: дальний бой
- Оружие: снайперская винтовка
- Особенности: повышенный урон на дальней дистанции, низкое здоровье

### Инженер (Engineer)
- Специализация: поддержка и оборона
- Оружие: дробовик, взрывчатка
- Особенности: может размещать турели и укрепления, ремонтировать снаряжение

## Серии убийств и награды
- 3 убийства подряд: разведывательный дрон
- 5 убийств подряд: усиленный бронежилет
- 7 убийств подряд: авиаудар

## Генерация карт
Плагин поддерживает автоматическую генерацию карт с различными темами:
- Стандартная
- Джунгли
- Зимняя
- Пустыня
- Руины

Каждая карта включает:
- Две базы команд с укреплениями
- Несколько контрольных точек
- Реалистичный ландшафт с горами и холмами
- Станции пополнения боеприпасов и здоровья
- Тактические укрытия и оборонительные позиции

## Система голосового чата
Плагин интегрируется с модулем VoiceChat и поддерживает следующие каналы:
- Командный канал (слышат только члены вашей команды)
- Тактический канал (слышат ближайшие союзники)
- Общий канал (слышат все игроки в определенном радиусе)

## Конфигурация
В игре доступны настройки различных параметров:
- Продолжительность игры
- Количество очков для победы
- Интервал респауна
- Количество контрольных точек
- Расстояние между базами
- Материалы для создания баз и флагов
- Настройки голосового чата

## Требования
- Minecraft Server 1.21+
- Java 17 или выше
- Плагин Simple Voice Chat (опционально для голосовой связи)
